README — EEG / BCI Coursework Repository

This repository contains EEG data and analysis artifacts produced as part of the
ECBM 4090 Brain–Computer Interface course.

The repository is organized by lab and project, and includes both raw EEG recordings
and analysis materials demonstrating a range of core EEG and BCI concepts.

Contents include:
- Raw EEG recordings collected using g.USBamp hardware
- MATLAB Live Scripts (.mlx) containing full analysis workflows
- Homework and lab reports (PDFs) documenting methods, results, and interpretation
- Simulink models used for online and real-time BCI experiments
- Supporting resources (channel location files, EEGLAB, etc.)

Across the labs and projects, the work covers fundamental EEG and BCI tasks such as:
- Artifact detection and filtering
- Bipolar vs monopolar referencing
- Neurofeedback and envelope extraction
- Event-related potentials (N200, P300)
- Auditory and visual evoked responses (ASSR, SSVEP)
- P300 speller systems
- Motor imagery classification using CSP and LDA
- Closed-loop and feedback-based BCI paradigms

Each Motor Imagery directory includes:
- Raw EEG recordings (.mat)
- MATLAB Live Scripts (.mlx) showing the full CSP + classification pipeline
- PDFs documenting experimental design, analysis choices, and results

No data has been altered; files are organized to clearly reflect experimental context
and analysis workflow.

This repository is intended to demonstrate hands-on experience with EEG data
collection, preprocessing, analysis, and interpretation in a BCI setting.
